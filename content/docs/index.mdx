ComfiConf lets you edit plugin settings at [app.comficonf.com](https://app.comficonf.com) instead of
hand-editing YAML. You install the ComfiConf bridge plugin on your server, pair the server with your account
once, and open any plugin that supports ComfiConf. The plugin checks, saves and activates each change itself,
and tells you what really happened.

## Set up your server

Five short steps take a new server from nothing to its first applied change:

1. [Check the requirements](/getting-started/requirements): Paper or Purpur 26.1.2, 26.2 or 26.3 on Java 25.
2. [Install the bridge](/getting-started/install-the-bridge): one JAR in your `plugins` folder, nothing to
   configure.
3. [Create an account](/getting-started/create-an-account) at app.comficonf.com.
4. [Pair your server](/getting-started/pair-your-server) with <CommandChip>/comficonf pair</CommandChip> and the
   code it shows.
5. [Make your first edit](/getting-started/first-edit), from finding a setting to applying it.

<Callout title="What ComfiConf never does on your server">
  The bridge cannot browse, read or write files, run console commands, or execute code. ComfiConf only reads
  and changes the settings that a plugin exposes through the ComfiConf API, and that plugin decides how they
  are checked, saved and activated. [Read more](/getting-started/what-is-comficonf).
</Callout>
